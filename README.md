# Toothent Dental Clinic Website

Website for Toothent Dental Clinic, Opposite KSEB, Syed Nagar, Taliparamba, Kannur, Kerala.

## Pages

- `index.html`: Home
- `about.html`: About Us
- `treatments.html`: Treatments
- `contact.html`: Contact and appointment form (sends the request via WhatsApp)

## Structure

- `css/styles.css`: all styles
- `js/main.js`: header, carousels, before and after slider, appointment form
- `assets/`: logo, icons and photos

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or serve the folder with any static server, for example:

```
npx http-server -p 5173
```
